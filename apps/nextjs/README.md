# apps/nextjs

A minimal Next.js example of running the agent server-side: `@nanocodana/core`
with OpenAI (set the `OPENAI_API_KEY` environment variable) inside
`app/api/chat/route.ts`, streamed to a React page built on `useChat`. Part of
the nanocodana monorepo — run it from the repo root with
`npm run dev -w apps/nextjs`.
